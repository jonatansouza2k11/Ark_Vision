🔑 CONFIGURAR CHAVES SSH (Recomendado)
─────────────────────────────────────

1. Gere chave SSH:
   ssh-keygen -t ed25519 -C "seu_email@example.com"

2. Copie a chave pública:
   Windows: type %USERPROFILE%\.ssh\id_ed25519.pub
   Linux:   cat ~/.ssh/id_ed25519.pub

3. Cole em GitHub Settings > SSH and GPG keys

4. Configure git:
   git config --global user.name "Seu Nome"
   git config --global user.email "seu_email@example.com"

🆘 PROBLEMAS COMUNS
───────────────────

"fatal: repository not found"
  → Verifique a URL do repositório
  → Verifique suas credenciais GitHub

"Permission denied (publickey)"
  → Configure chaves SSH
  → Ou use token de acesso pessoal (PAT)

"The following untracked files would be overwritten"
  → git clean -fd
  → git reset --hard
